Contexto do Projeto

O projeto Futuro de Finanças visa transformar a forma como dados financeiros são processados, analisados e aproveitados para tomada de decisão estratégica. Buscamos pessoas Engenheiras de Dados que tenham forte experiência técnica, visão analítica e perfil inovador para atuar em um ambiente desafiador, com tecnologias de ponta e entregas de alto impacto.


Responsabilidades

Projetar, desenvolver e manter pipelines de dados robustos e escaláveis, garantindo a qualidade, governança e observabilidade dos dados.

Atuar em projetos de processamento massivo de dados utilizando Apache Spark / PySpark, AWS Glue e EMR.

Implementar rotinas de orquestração e automação de fluxos de dados com Apache Airflow, Step Functions e EventBridge.

Modelar e gerenciar armazenamento de dados em S3, Open Table Formats e arquitetura Lakehouse, incluindo data contract e schema evolution.

Desenvolver e otimizar consultas em Data Warehouses (Redshift, Athena), bancos relacionais (RDS) e NoSQL (DynamoDB).

Aplicar práticas de governança de dados com Lake Formation, OpenLineage e ferramentas de catalogação e lineage.

Monitorar e garantir a observabilidade dos ambientes de dados com CloudWatch, DataDog e práticas de melhoria contínua.

Explorar e implementar soluções de IA e GenAI aplicadas a dados, utilizando Amazon Bedrock, MCP Server AI Agent, técnicas de prompt engineering, RAG, embeddings, guardrails e avaliação (eval).

Contribuir com a cultura de automação ("toil reduction"), DevOps (Dev + Infra + Sec), planejamento de capacidade e otimização de custo x performance.

Participar da resolução de incidentes, elaboração de runbooks e promoção de práticas de melhoria contínua nos processos de dados.

Requisitos Técnicos

Processamento e transformação: Experiência em Apache Spark / PySpark, AWS Glue, EMR.

Consultas e armazenamento: Domínio de SQL e NoSQL, modelagem de dados em S3, Redshift, DynamoDB, RDS.

Orquestração: Atuação comprovada com Apache Airflow, Step Functions, EventBridge.

Lakehouse e governança: Vivência com Open Table Formats, arquiteturas Lakehouse, data contract, schema evolution, Athena, Lake Formation, OpenLineage.

Observabilidade: Uso de CloudWatch, DataDog ou ferramentas similares.

IA / GenAI aplicada a dados: Experiência com Amazon Bedrock, MCP Server AI Agent, prompt engineering, RAG, embeddings, guardrails e avaliação.

Spec Driven Development: Conhecimento e aplicação de desenvolvimento guiado por especificação.
